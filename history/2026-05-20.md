# 2026-05-20 - 修复商品评论功能问题

## 问题概述

在 `secondhand.ts` 中发现并修复了两个问题：

### 1. submitReview 函数缺失

**问题描述**：在 `rejectReturnOrder` 函数后面有重复损坏的代码，且 `submitReview` 函数完全没有定义，导致商品评论功能无法使用。

**修复内容**：
- 删除了损坏的重复代码行
- 添加了完整的 `submitReview` 函数定义

### 2. API 路径不匹配

**问题描述**：前端调用的 API 路径 `/items/${itemId}/reviews` 与后端实际端点 `/reviews` 不匹配。后端期望 `itemId` 在请求体中，而不是 URL 路径参数。

**修复内容**：
- 修改 `submitReview` 函数，将 `itemId` 放入请求体中
- 更新了 `secondhand-api.md` 文档以反映正确的 API 路径

## 修改文件

1. **FireBirdCilent/src/utils/secondhand.ts**
   - 删除了第 501-508 行的损坏代码
   - 添加了 `submitReview` 函数（第 505-512 行）
   - 修改了 API 调用路径，从 `/items/${itemId}/reviews` 改为 `/reviews`，并将 `itemId` 放入请求体

2. **FireBirdCilent/src/utils/secondhand-api.md**
   - 更新了第 7 节"提交评价"的 API 路径
   - 添加了 Headers 说明
   - 添加了 itemId 参数到请求体
   - 更新了响应格式以匹配实际后端返回

## 修复后的代码

### submitReview 函数
```typescript
export async function submitReview(itemId: string | number, payload: {
  rating: number
  comment: string
}): Promise<any> {
  const { data } = await axios.post(`${BASE}/reviews`, { itemId, ...payload }, {
    headers: getHeaders(),
  })
  return data
}
```
