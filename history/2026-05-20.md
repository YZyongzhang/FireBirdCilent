# 2026-05-20 - 修复商品评论功能及TypeScript类型错误

## 问题概述

本次修复了商品评论功能问题和两处 TypeScript 类型错误。

---

## 一、submitReview 函数缺失

**问题描述**：在 `secondhand.ts` 中发现 `rejectReturnOrder` 函数后面有重复损坏的代码，且 `submitReview` 函数完全没有定义，导致商品评论功能无法使用。

**修复内容**：
- 删除了损坏的重复代码行
- 添加了完整的 `submitReview` 函数定义

---

## 二、API 路径不匹配

**问题描述**：前端调用的 API 路径 `/items/${itemId}/reviews` 与后端实际端点 `/reviews` 不匹配。后端期望 `itemId` 在请求体中，而不是 URL 路径参数。

**修复内容**：
- 修改 `submitReview` 函数，将 `itemId` 放入请求体中
- 更新了 `secondhand-api.md` 文档以反映正确的 API 路径

---

## 三、LoginView.vue 类型错误

**问题描述**：`charColors.value = Array.from(...)` 返回类型 `(string | undefined)[]` 无法赋值给 `string[]`。

**修复内容**：
- 将 `colors[Math.floor(Math.random() * colors.length)]` 改为使用索引 `(_, i) => colors[i % colors.length]!`
- 使用非空断言 `!` 确保类型安全

---

## 四、AdminUsersView.vue 类型错误

**问题描述**：`UsersResponse` 接口缺少 `message` 属性，但代码中使用了 `res.message`。

**修复内容**：
- 在 `UsersResponse` 接口中添加可选的 `message?: string` 属性

---

export async function submitReview(itemId: string | number, payload: {
  rating: number
  comment: string
}): Promise<any> {
  const { data } = await axios.post(`${BASE}/reviews`, { itemId, ...payload }, {
    headers: getHeaders(),
  })
  return data
}
