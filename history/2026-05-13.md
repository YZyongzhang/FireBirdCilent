# 2026-05-13 二手交易模块更新

## 概述

本次更新根据 prompt.md 的要求，对二手交易模块进行了全面重构，实现了完整的交易页面功能，包括商品添加、购物车、客服、模拟支付、评价和搜索功能。

## 主要更改

### 1. 更新接口文档

**文件**: `src/api/secondhand_api.md`

更新了二手交易模块的 API 接口文档，新增了以下接口：

- **商品管理**: 获取商品列表、商品详情、发布商品、编辑商品、删除商品、商品评价
- **购物车**: 获取购物车列表、添加商品、更新数量、移除商品、清空购物车
- **客服消息**: 获取聊天记录、发送消息、获取未读消息数
- **订单与支付**: 创建订单、获取订单列表、模拟支付、取消订单
- **商品评价**: 提交商品评价
- **分类**: 获取所有分类

### 2. 新增 API 服务文件

**文件**: `src/utils/secondhand.ts`

创建了完整的 TypeScript API 服务模块，包含：

- 完整的类型定义（Item、CartItem、Message、Review、Order 等）
- 所有 API 调用函数（使用 axios 封装）
- 自动携带用户鉴权信息

### 3. 重写二手交易页面

**文件**: `src/views/SecondhandView.vue`

完全重写了二手交易页面，实现了以下功能：

- **商品列表**: 从后端获取商品列表，支持搜索和分类筛选，支持分页
- **商品详情**: 展示商品详细信息，包含图片、描述、价格、卖家信息
- **发布商品**: 表单发布新商品，包含标题、描述、价格、分类
- **购物车**: 完整的购物车功能，包括查看、修改数量、删除、清空、结算
- **客服聊天**: 与卖家实时聊天功能，支持发送和接收消息
- **模拟支付**: 支持支付宝、微信、PayPal 三种支付方式
- **商品评价**: 用户可以对已购买的商品进行评分和评论
- **我的订单**: 查看用户的所有订单记录及状态

## 技术特点

1. **无硬编码数据**: 所有数据均通过 API 与后端交互，前端仅负责展示
2. **TypeScript 类型安全**: 完整的类型定义，确保代码质量
3. **模块化设计**: API 服务与视图分离，便于维护
4. **用户鉴权**: 自动携带用户信息到所有请求头
