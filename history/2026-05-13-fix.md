# 2026-05-13 修复客服聊天 seller undefined 问题

## 问题描述

二手交易平台打开客服聊天记录进行聊天的时候，出现 `seller` 为 `undefined` 的情况。

## 问题分析

1. `Item` 类型定义中，`seller` 字段是可选的（`seller?: { id: string | number; name: string }`）
2. `openChat` 函数直接访问 `seller.seller.id`，如果后端返回的数据中没有 `seller` 对象，则会报错
3. 按钮没有禁用状态，用户点击后没有任何反馈

## 修复方案

### 1. 改进 `openChat` 函数
- 添加对 `seller` 和 `seller.id` 的空值检查
- 当卖家信息不完整时，弹出提示告知用户
- 优化卖家名称的获取逻辑（支持 `sellerName` 字符串形式）

### 2. 添加计算属性
- 添加 `canContactSeller` 计算属性，判断是否可以联系卖家

### 3. 更新按钮状态
- 根据 `canContactSeller` 状态禁用/启用按钮
- 禁用时显示"暂无法联系卖家"，提供更好的用户体验

## 修改文件

- `src/views/SecondhandView.vue`:
  - 修改 `openChat` 函数，添加空值检查和错误提示
  - 添加 `canContactSeller` 计算属性
  - 更新"联系卖家"按钮，添加禁用状态和动态文本

## 效果

- 当卖家信息不完整时，按钮会被禁用并显示"暂无法联系卖家"
- 即使用户点击了按钮，也会弹出友好的提示信息
- 避免了 `seller undefined` 的错误
